# CTC Digital Nurture 5.0 – Deepskilling

# Week 6 – Angular 20 Hands-On

## Project Name

**Student Course Portal**

---

## Overview

The Student Course Portal is an Angular 20 application developed as part of the **CTC Digital Nurture 5.0 – Deepskilling Program**. The project demonstrates Angular fundamentals, routing, standalone components, forms, services, and REST API integration using JSON Server.

---

## Technologies Used

- Angular 20
- TypeScript
- HTML5
- CSS3
- RxJS
- Angular Router
- JSON Server
- HttpClient
- Reactive Forms
- Template-Driven Forms

## Running the Project

### Install Dependencies

```bash
npm install
```

### Start JSON Server

```bash
json-server db.json --port 3000
```

### Run Angular Application

```bash
ng serve
```

### Open in Browser

```
http://localhost:4200
```
